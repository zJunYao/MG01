## 导入与验证

资源已经生成，可直接使用预制体。主角原观察场景仍使用原有动作列表；新动作可在动画窗口中查看。

首次准备图片时，在项目根目录运行（需要 Python 和 Pillow）：

```powershell
python Tools/Art/prepare_character_sprites.py I:/AI/OpenCode/gif
```

然后在 Unity 执行菜单 **测试 → 角色 → 导入奔跑与三个哥布林**。已存在目标动画或预制体时，导入工具会拒绝覆盖。

验证已导入资源使用 **测试 → 角色 → 验证奔跑与三个哥布林**，检查切片尺寸、资源数量、控制器与预制体引用、循环与时长，并逐帧采样。走路专项使用 **测试 → 角色 → 验证三个怪物走路动画**。

走路图集准备脚本为 `Assets/Test/Editor/prepare_monster_walk.py`（需要 Python 和 Pillow），之后执行 **测试 → 角色 → 导入三个怪物走路动画**；已有动画时会拒绝覆盖。走路追加不重新生成怪物、待机或攻击资源，保留盗贼攻击裁剪、场景站位和攻击点配置。
