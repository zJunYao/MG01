# 模型显示系统

## 接入

`SceneModelView` 是统一 UI 入口，实现 `IModelView`。两种模式均使用专用相机 → 透明 RT → RawImage。

- 在页面下创建带 RectTransform 的空节点并添加 SceneModelView，设置区域尺寸；首次显示时自动创建铺满入口的 RawImage 子节点。
- 或使用 `Assets/GameResources/UI/UIPrefab/SceneModelView.prefab`，其中已配置 RawImage 和显示材质。
- `stage.prefab` 已嵌套该预制体，节点名 ModelViewRoot，位于 bg_scene 之后、前景控件之前，默认场景模式。
- 空节点方式用于打包时，应显式配置 Display Material 为 `Assets/GameResources/UI/Materials/SceneModelView.mat`，确保材质和 Shader 被资源构建流程收录。运行时 Shader.Find 仅作为已有 Shader 可用时的回退。

## 页面调用示例

```csharp
SceneModelView view = stageRoot.transform.Find("ModelViewRoot").GetComponent<SceneModelView>();
IModelView modelView = view;

// 模型资源由现有资源系统加载；该入口克隆模型，不释放调用方的预制体资源句柄。
modelView.ShowAvatar(rolePrefab, new AvatarViewSettings
{
    padding = 1.2f,
    zoom = 1f,
    framingOffset = Vector2.zero
});

// 切换到场景区域；现有模型的层、站位、动画和所有权保持不变。
modelView.ShowScene(new SceneModelViewSettings
{
    modelLayers = LayerMask.GetMask("ModelPreview"),
    cameraOffset = new Vector3(0f, 0f, -10f),
    orthographicSize = 4f
}, sceneAnchor);

modelView.SetVisible(false); // 暂停拍摄并隐藏 Avatar 展示空间，保留资源
modelView.SetVisible(true);  // 恢复并复用资源
modelView.Clear();           // 释放拍摄相机、RT 和独立 Avatar 展示实例
```

一个入口同时使用一种模式；多个入口可以同时使用。配置在调用时复制，修改调用方配置不会暗中影响已开启的窗口。`SetCameraAnchor`、`SetModelLayers` 调整当前场景模式；`RefitAvatar` 用于主动换装后的重新适配。

## 层级与职责

- UI 入口：SceneModelView，处理尺寸、材质、模式切换和生命周期。
- 共用拍摄：ModelViewCapture，每个入口独占相机和 RT；无页面依赖。
- Avatar 展示：AvatarViewSpace，管理展示实例、取景及空间分配。
- 公共配置和调用契约：ModelViewSettings.cs。

相机和 Avatar 展示空间是独立的场景根节点，不继承 Canvas 变换。UI 移动只改变显示位置；宽高比变化重新计算投影，不逐帧重新测量模型动画包围盒。

## Avatar

- 使用专门的 `AvatarPreview` 层（第 9 层）；递归设置展示副本，不修改预制体。
- 按可见 Renderer 的初始包围盒将模型最长边归一化为 2 单位；粒子不参与自动取景。
- 展示单元相隔 100 单位，位于 Z=10000 的专用展示区域；相机裁剪距离和横纵视野受限，防止极端 UI 比例拍到相邻单元。此区域应保留给展示系统。
- 默认正交、居中，支持旋转、留白、缩放和偏移；窗口宽高比变化可调整取景，动画本身不会触发镜头抖动。
- 展示实例的碰撞器、刚体模拟、额外相机、AudioListener 和 Animator 根运动会关闭。
- 传入纯展示预制体；普通 MonoBehaviour 仍会执行，业务脚本不应自行移动展示根、修改层或向场景外生成对象。动态添加的模型子节点需使用 AvatarPreview 层。
- 动画振幅超过初始包围盒时调整 padding；极端长宽比为了隔离会限制视野，可调整窗口比例。

## SceneModelView

- 按层和区域拍摄，默认 `ModelPreview`（第 8 层）；不是模型白名单。
- 支持单个或多个场景模型，符合层配置的新模型进入镜头会自然显示。
- 始终排除 AvatarPreview，避免场景模式拍到展示副本。
- 不改变已有场景模型的父节点、位置、动画、层或生存期；场景作者负责给模型及需要显示的特效配置拍摄层。
- 普通场景相机应按用途排除展示层，避免重复显示。该组件不改写其他相机。
- 多个场景窗口可以观察同一片区域，也可以设置不同的区域和锚点。

## 显隐、释放与质量

- SetVisible(false)、入口或父节点停用：停止拍摄，停用独立 Avatar 空间，保留 RT 和绑定。
- 再次显示：恢复拍摄。仅设置 CanvasGroup.alpha=0 不会触发生命周期，应同时调用 SetVisible(false)。
- Clear、模式切换、销毁组件：释放自身创建的相机、RT、Avatar 实例。不会销毁调用方传入的资源或场景模型。
- 页面框架若只是隐藏页面但希望彻底卸载，应显式调用 Clear；后续重新调用 ShowAvatar 或 ShowScene。
- RT 根据显示区域分配；屏幕空间 Canvas 考虑 scaleFactor，世界空间 Canvas 使用设计尺寸。默认最长边 2048，尺寸相同时复用，尺寸变化时重建。
- 默认使用已有预乘透明材质，支持 UI 遮罩、透明度与颜色。RawImage 输出由入口独占管理，不应同时由其他代码写入 texture 或 enabled。
- 创建 RT 失败后停止重试并报告错误，重新调用显示接口可重试。

## 与旧实现的区别

不再通过 BindCamera 接管外部相机。相机统一由入口创建、管理和释放，场景拍摄使用 ShowScene 的配置与锚点。原有自定义实例上的旧取景序列化字段需迁移到 Scene Settings；本仓库通用预制体已更新。
