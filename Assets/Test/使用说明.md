# 主角资源与观察场景

## 使用方法

1. 打开 `Assets/Test/Scenes/HeroPreview.unity`。
2. 点击 Unity 顶部播放按钮。请勿使用框架的“启动游戏”快捷键，以免跳到原启动场景。
3. 右侧面板可切换右下方向的待机、呼吸和魔法攻击，支持暂停、逐帧、进度拖动、倍速、缩放及明暗背景。
4. 面板空间不足时可以滚动。

## 可复用资源

- 主角：`Assets/GameResources/Characters/Hero/Hero.prefab`，包含 SpriteRenderer 与 Animator，不挂载测试脚本。
- 动画：`Assets/GameResources/Characters/Hero/Animations`，仅保留右下方向的 3 个片段（魔法攻击、待机、呼吸待机）。默认状态为右下呼吸；其他方向及静态姿势片段已删除。
- 攻击在动画控制器中不循环；观察工具可单独开启循环预览。攻击帧包含角色和魔法特效，原素材没有独立特效层。
- 精灵：`Assets/GameResources/Characters/Hero/Sprites`，只保留 Row2（41 帧攻击）、Row3（8 帧待机）、Row5（17 帧呼吸），总计 66 帧；每格 256×256，中心轴点，100 像素/单位，点过滤、无压缩、无 Mipmap。
- 原始图集和元数据：`Assets/GameResources/Characters/Hero/Source`，保留完整原件作备份，不用于角色播放。原图宽度为 10496，实际使用的是无损重新排布的右下方向图集，最大边长不超过 2048。
- 原素材没有跑步、受击或其余方向的动态动画，本次不伪造或镜像补全。
- 原导出未记录帧率：攻击按描述约 3 秒播放（41 帧）；待机与呼吸按每秒 8 帧播放，可在动画片段中调整。

## 范围与隔离

所有新增 C# 脚本均位于 `Assets/Test`：运行观察工具 `HeroPreview.cs`，编辑器导入工具 `Editor/HeroAssetBuilder.cs`。

导入菜单为“测试 → 主角 → 导入资源并创建观察场景”。资源已经生成，无需再次执行；为防止覆盖手工调整，检测到现有预制体或测试场景后会拒绝重复生成。

观察场景不加入构建列表，不修改框架、原场景、启动流程、包依赖或项目设置。
