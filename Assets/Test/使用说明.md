# 主角资源与观察场景

## 使用方法

1. 打开 `Assets/Test/Scenes/HeroPreview.unity`。
2. 点击 Unity 顶部播放按钮。请勿使用框架的“启动游戏”快捷键，以免跳到原启动场景。
3. 左上角面板可以切换“主角 / 战士 / 盗贼 / 酋长”。主角保留右下方向动作，怪物支持左下方向待机、攻击和走路；各角色独立播放，支持暂停、逐帧、进度拖动、倍速、缩放及明暗背景。
4. 面板空间不足时可以滚动。
5. “怪物全部待机 / 怪物全部攻击”可同时切换三个怪物。攻击默认在测试中循环，可针对每个怪物关闭循环。

## 主角受击

- 在 HeroPreview 左上角选择“主角”，点击“受击 · 右下”即可播放，支持暂停、逐帧、倍速和进度拖动。动画资源本身不循环，面板的循环选项可用于重复观察；关闭面板循环后停在末帧。
- 动画为 `Assets/GameResources/Characters/Hero/Animations/Hit_south-east.anim`，共 9 帧、5 FPS、1.8 秒；透明图集为 `Hero/Sprites/Hit_south-east.png`，原件备份为 `Hero/Source/Hit_south-east.gif`（路径相对于角色资源目录）。
- 原控制器追加 `Hit_south-east` 状态，默认仍为呼吸待机；没有修改主角预制体的组件或站位，也没有自动把怪物攻击接到主角受击或伤害逻辑。
- 验证菜单：“测试 → 主角 → 验证右下受击动画”。导入工具和图集准备脚本位于 `Assets/Test/Editor`，检测到已有受击动画时拒绝覆盖手工调整。

## 怪物攻击前移动

- 选择怪物的“攻击”、点击“重播”攻击或“怪物全部攻击”时，先从当前位置平滑移动到该怪物的攻击目标，再从攻击首帧开始播放。移动期间循环播放走路动画，不会提前播放攻击。返程同样播放走路，到达原位后切回待机或进入下一轮。
- 三怪物的走路动画均来自用户提供的 GIF：8 帧、5 FPS、1.6 秒循环，保留原生透明度。素材只有左下方向，去程和返程先共用同方向走路，不镜像或生成其他朝向。在面板选择“走路”可原地单独预览，不触发位移。
- 攻击目标是角色 Transform 的世界坐标，不是脚底锚点：战士 `(-2.29, -0.36, 0)`，盗贼 `(-2.248, -0.248, 0)`，酋长 `(-2.47, -0.35, 0)`。
- 在“主角观察工具”的 MonsterPreview → Actors 中，通过 `Attack Position` 调整每个怪物的目标，通过 `Move Speed` 调整移动速度（默认 4 世界单位/秒）。在非播放模式修改并保存场景即可保留。
- 勾选怪物面板的“暂停播放（回到原位）”时，去程、攻击中或返程都会立即回到本轮出发位置，显示待机首帧并暂停。取消暂停后重新执行“前往攻击点 → 攻击 → 返回”。待机时暂停不改变位置；逐帧和进度拖动仍只冻结动画，保留定位检查能力，不触发回原位。此处指测试面板的暂停，不是 Unity 顶部的全局暂停。
- 播放倍速同时影响去程和返程；移动中暂时禁用攻击进度拖动和逐帧，避免跳过移动阶段。切换待机会取消移动并留在当前位置，重播攻击则重新执行到达检查。
- 攻击开始时记录当时的实际位置，完整播放攻击后，以相同移动速度返回该位置，返程期间播放走路动画，暂停则立即回到原位显示待机。关闭循环时返回后待机，开启循环时重复“出发 → 攻击 → 返回”的完整流程。
- 攻击过程中重播会保留本轮出发位置，不会把攻击点或返程途中位置误记为原位置；切换待机会取消整个流程并留在当前位置，下次攻击重新记录出发位置。平时仍可在 Scene 中移动角色，只有去程和返程会主动更新位置。
- 验证菜单：“测试 → 角色 → 验证怪物先移动再攻击”，在播放模式检查三怪物的目标、移动、暂停、倍速和攻击时序；不保存或覆盖场景站位。

## 怪物站位与测试代码

- 战士：右侧偏上；盗贼：右侧偏下；酋长：最右侧。主角保持左侧红框位置。
- 场景中实例化原怪物预制体，不修改其资源或控制器。按前后站位调整实例的精灵排序。
- 默认使用场景中角色自身的 Transform 位置。退出播放模式，在 Hierarchy 选择 `Hero`、`GoblinWarrior`、`GoblinThief` 或 `GoblinChief`，在 Scene 中使用移动工具拖动，或修改 Inspector 的 Transform → Position，然后保存场景。再次播放会保持调整后的站位。
- 播放时也可在 Scene 中移动角色，不会被预览脚本拉回；但 Unity 默认不会保留播放模式中的场景修改，需要永久保存时请在非播放模式下调整。
- `Assets/Test/HeroPreview.cs` 和 `Assets/Test/MonsterPreview.cs` 负责独立动画和面板控制。两者的 `Lock To Viewport` 默认关闭；如需恢复原参考图的屏幕固定站位，可分别启用主角或怪物的该开关。开启后会覆盖 Transform 位置，怪物此时使用 `Foot Position`（屏幕左下为 0,0，右上为 1,1）。镜头缩放在默认模式下只改变观察范围，不会重新排列角色。
- `Assets/Test/Editor/MonsterSceneSetup.cs` 提供一次性场景配置及验证菜单，不修改背景、主角资源或框架。
- 验证菜单：“测试 → 角色 → 验证怪物观察场景并预览攻击”，逐帧验证三个怪物的九个动作；播放模式下还会触发三个怪物攻击。“验证三个怪物走路动画”单独检查走路资源，“验证怪物先移动再攻击”检查移动时播放走路及暂停回位。

## 可复用资源

- 主角：`Assets/GameResources/Characters/Hero/Hero.prefab`，包含 SpriteRenderer 与 Animator，不挂载测试脚本。
- 动画：`Assets/GameResources/Characters/Hero/Animations`，仅保留右下方向的 3 个片段（魔法攻击、待机、呼吸待机）。默认状态为右下呼吸；其他方向及静态姿势片段已删除。
- 攻击在动画控制器中不循环；观察工具可单独开启循环预览。攻击帧包含角色和魔法特效，原素材没有独立特效层。
- 精灵：`Assets/GameResources/Characters/Hero/Sprites`，只保留 Row2（41 帧攻击）、Row3（8 帧待机）、Row5（17 帧呼吸），总计 66 帧；每格 256×256，中心轴点，100 像素/单位，点过滤、无压缩、无 Mipmap。
- 原始图集和元数据：`Assets/GameResources/Characters/Hero/Source`，保留完整原件作备份，不用于角色播放。原图宽度为 10496，实际使用的是无损重新排布的右下方向图集，最大边长不超过 2048。
- 原素材没有跑步、受击或其余方向的动态动画，本次不伪造或镜像补全。
- 原导出未记录帧率：攻击按描述约 3 秒播放（41 帧）；待机与呼吸按每秒 8 帧播放，可在动画片段中调整。

## 范围与隔离

所有新增 C# 脚本均位于 `Assets/Test`：运行观察工具 `HeroPreview.cs`，编辑器导入工具 `Editor/HeroAssetBuilder.cs`。

导入菜单为“测试 → 主角 → 导入资源并创建观察场景”。资源已经生成，无需再次执行；为防止覆盖手工调整，检测到现有预制体或测试场景后会拒绝重复生成。

观察场景不加入构建列表，不修改框架、原场景、启动流程、包依赖或项目设置。
