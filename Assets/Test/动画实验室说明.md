# 动画实验室

## 使用

1. 打开 `Assets/Test/Scenes/AnimationLab.unity`，使用 Unity 顶部播放按钮运行。
2. 默认选择酋长攻击；可以切换主角、战士、盗贼和各自已有动作。
3. 支持暂停、逐帧、进度拖动、倍速、循环和镜头缩放。
4. 调整“额外高度”“起跳进度”“最高点进度”“落地进度”。进度是攻击总时长的比例，面板同时显示对应秒数。
5. “查看最高点”会切回酋长攻击并暂停在最高点；关闭“启用附加高度”可以在同一时刻对比原动作。
6. 满意后点击“保存跳跃参数到独立配置”。不点击保存，退出播放会丢弃本次临时参数；“还原已保存参数”可撤回尚未保存的调整。

## 参数保存

独立配置位于 `Assets/Test/Settings/ChiefJump.asset`，可在非播放模式下通过 Inspector 修改并保存。播放面板的保存按钮也写入该文件，退出播放后仍保留。

初始参数：附加高度 0.65 世界单位、起跳 25%、最高点 45%、落地 68%。这是便于比较的初始方案，不代表已按原素材逐帧完成最终打磨。

当前只是酋长攻击的额外视觉位移，原图片里的跳跃仍然保留。100 像素约为 1 世界单位。地面锚点和影子保持在地面，显示节点额外上移；原图内绘制的特效会随图片一起移动，因此需要在地面特效出现前让附加位移归零。

## 隔离与验证

- 不修改原 `HeroPreview` 场景、角色预制体、动画资源、框架、构建列表或包配置。
- 所有新脚本及参数位于 `Assets/Test`。
- 为避免丢失未保存内容，创建菜单会附加打开新场景。运行实验室时临时停用其他已加载场景的根物体，退出播放后恢复；推荐日常单独打开此场景运行。
- 菜单“测试 → 动画实验室 → 验证配置和场景”检查四角色全部动画帧、配置引用和高度曲线；播放模式下还检查角色切换、最高点附加高度及落地复位，并暂停在酋长最高点。
- 参数只在动画实验室生效，不会自动应用到原观察场景或正式战斗逻辑。
