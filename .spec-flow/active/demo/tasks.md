# 单场战斗 Demo 开发任务

## 状态与执行约定

- 需求、技术设计和本任务清单已由用户确认；用户已授权开始第一阶段。
- 用户指定：按阶段批量执行，不逐任务确认；每一阶段结束后停止并请求进入下一阶段。
- 开始实现前须确认本清单，不把执行模式确认当作尚未展示的任务清单已批准。
- 每项执行前读取本清单与 `design.md`，检查依赖；完成后及时勾选并记录实际文件和证据。
- 复杂度“低/中”对应低/中等复杂度；每项以1～2次主要编辑或测试调用为目标，通常涉及1～3个文件。若实际超出，先细分，不以扩大单次补丁掩盖复杂任务。
- 失败或阻塞立即停止；不得绕过未满足依赖或勾选未测试任务。编译错误先修复再继续引用新增类型。
- Unity API使用前按可用工具核验；修改脚本后刷新并检查编译控制台。自动化、编辑器、Windows和美术分别验收。
- 表现临时版本不等待最终素材，但最终美术验收等待用户素材；不为等待素材阻塞纯规则阶段。
- 不创建工作树、不提交或推送代码、不更改无关平台设置，除非另获授权。
