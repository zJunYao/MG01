# 术语表（GLOSSARY）

> 更新日期：2026-10-22。与 GDD v0.3.3 同步。一词一义；以下 Demo 口径不自动约束所有正式职业。旧 Word 术语表未同步。

| 术语 | 定义与当前适用规则 |
|---|---|
| 背包 | 装载并摆放参与行动的道具；Demo为7列×5行、35格 |
| 格子 | 背包占用与相邻判断的最小空间单位 |
| 备用区 | 存放未装入背包的道具，Demo为8槽、一件一槽，不拼形状，不产生战斗效果 |
| 道具／物品 | 本文统一用“道具”；“物品系统”是沿用的章节名称，不代表另一类对象 |
| 道具定义 | 名称、形状、效果等静态定义，与某场战斗中的实例区分 |
| 道具实例 | 本场具体持有的道具，记录位置与存在状态；药水消耗销毁实例，不删除定义 |
| 战斗会话 | 唯一拥有某场可变战斗状态的运行对象；界面显隐不重建，重开使旧会话与回调失效 |
| 配置批次 | 同次导出的运行表及版本/哈希清单；开战前整体校验，防止混用不同批次的表 |
| 占格形状 | 道具在背包占用的格子集合；Demo宽×高按列×行表示 |
| 旋转 | 背包内双击道具旋转90°；备用区不旋转，越界或重叠则保留原状 |
| 触发 | 确认行动后按规则执行道具效果，不是拖入背包立即生效 |
| 相邻增伤 | 符石与攻击道具占格上下左右共边时增加固定伤害；斜角不算，多边接触不重复 |
| 位置排序 | 最左列优先，同列最上行优先；列优先而非逐行扫描，每件道具只执行一次 |
| 回合／轮 | 主角与存活敌人按次序各行动一次；战斗结束立即终止剩余行动 |
| 主角行动 | 包括备战调整、确认、道具自动执行；不能笼统称为全程无操作 |
| 备战／调整阶段 | 轮到主角时打开UIStage，自由整理、查看和选目标；不在每轮所有角色行动前另开一次 |
| 配置锁定 | 确认后不能调整背包或手动改目标，直到下次主角备战；自动转移目标不受此限制 |
| 自动执行 | 确认后系统依次执行道具或敌人行动，玩家不逐件点击发动 |
| 角色行动条 | 展示主角→战士→盗贼→首领的固定次序及当前行动者；不是速度积攒条 |
| 道具执行队列 | HeroAttackQueue的展示语义，包含攻击、护盾、恢复；只展示实际执行项，不可手动排序 |
| 增益类道具 | Demo符石提供被动增伤，不独立占队列步骤 |
| 跳过 | 条件不满足而不使用道具；不显示队列图标和跳过提示，满生命药水保留 |
| 主要目标 | 整套行动的主要敌方目标，备战时可点选或按钮切换 |
| 目标切换 | 按钮按战士→盗贼→首领循环，跳过死亡敌人 |
| 击杀转移 | 当前目标死亡后，从固定站位顺序开头找第一名存活敌人；不是从死者位置向后循环 |
| 溢出伤害 | 超过目标剩余生命的该次伤害，不转移给其他敌人 |
| 护盾 | 先于生命承伤；剩余值在下次主角进入调整阶段时清除 |
| 雷电法杖 | 1×3攻击装备，单次基础伤害6，主角原地施法 |
| 雷电帽 | 2×2攻击装备，召唤雷云单次基础伤害10，雷云不是持续召唤物 |
| 雷电符石 | 1格增益道具，相邻法杖与雷电帽各+2伤害，可同时强化两件 |
| 魔法泡泡 | 2×2防御装备，轮到其执行时获得9护盾，与攻击道具统一按位置排序 |
| 治疗药水 | 1×2消耗品，未满生命时自动恢复最多10生命并销毁，满生命保留且不入队 |
| 立即结束战斗 | 最后一敌死亡立即胜利，主角生命归零立即失败；后续道具不执行、不消耗 |
| 构筑 | 道具组合与背包布局形成的配置；Demo允许五件全部装入，不要求每轮换装 |
| 随机遭遇 | 正式游戏普通战斗胜利后由系统直接决定的事件，不采用路线选择；不在本Demo范围 |
| 商店 | 正式游戏随机遭遇的可能内容，可选择道具并提供恢复机会；不是每个战斗回合间必开 |
| 哥布林首领 | Demo三敌之一，蓄力与重击交替；不等同于已实现正式游戏最终首领进度 |
| 哥布林战士 | 每次行动进行二连击，每击3点伤害，逐次结算；第一击导致战斗结束则不再执行第二击 |
| 哥布林盗贼 | 每次行动进行一次普通攻击，伤害4点，不再采用二连击 |

## 命名与待定义项

- 资源现名 `HeroAttackQueue`、`UIStage` 等可沿用；资源名不改变上述术语含义。
- 道具标识沿用项目指令的 `snake_case`；具体ID、字段、配置文件和代码类名尚未确定。
- 冷却、星级、合成、货币、商店刷新及局外成长未在当前Demo确定，不保留旧模板示例作为默认规则。
