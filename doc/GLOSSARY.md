# 术语表（GLOSSARY）

> 使用说明：一词一义。GDD 和代码里的命名都以这里为准，新增名词先登记再使用。
> 示例行供参考，定稿前按你的实际设计修改。

| 术语 | 定义 | 示例 |
|---|---|---|
| 背包 | 玩家构筑的主界面，一块矩形网格 | 8 列 × 6 行 |
| 格子 | 背包的最小单位 | 1 格 = 1 单位面积 |
| 物品 | 可放入背包的实体：武器 / 防具 / 饰品 / 消耗品 | 铁剑、木盾、幸运币 |
| 物品形状 | 物品占用的格子形状（俄罗斯方块式） | 铁剑占 1×2 竖条 |
| 旋转 | 改变物品在背包中的朝向 | 顺时针 90° |
| 冷却 | 武器再次触发需要的回合数 | 铁剑冷却 2 回合 |
| 触发 | 满足条件时武器自动释放技能 | 回合开始时触发 |
| 相邻加成 | 物品相邻摆放时获得的增益 | 武器旁边放磨刀石 +2 伤害 |
| 星级 | 物品稀有度 / 合成等级 | 3 把 1 星铁剑合成 1 把 2 星 |
| 回合 | 战斗的最小时间单位，双方各行动一次 | 第 5 回合 |
| 自动战斗 | 回合内按背包配置自动结算，玩家不操作 | — |
| 构筑（Build） | 玩家整套背包布局 + 物品组合的策略 | 连击流、暴击流 |
| 流派 | 成型的构筑方向 | 灼烧流、护甲流 |
| 商店 | 回合间购买物品的界面 | 每关之间出现 |
| 刷新 | 重置商店出售的物品列表 | 每次 2 金币 |
| 金币 | 局内货币 | 击杀掉落、每关结算 |
| 关卡 / 层数 | 爬塔式推进的进度单位 | 共 15 层，每 5 层一个 Boss |
| Boss | 层数节点的高强度怪物 | 第 5 层 Boss：铁甲巨人 |
